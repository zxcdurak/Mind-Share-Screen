# Mind for Firefox — фикс демонстрации экрана и чата i.Mind для Firefox

Расширение для Firefox, которое чинит демонстрацию экрана и поле ввода чата в
видеоконференциях **i.Mind** (используется, например, на `e-class.tsu.ru`) — там,
где сайт показывает ошибку вида «Используемый браузер не поддерживает технологию
трансляции рабочего стола» и предлагает установить Chrome, IE или Яндекс.Браузер.

**Установить из каталога дополнений Firefox:**
<https://addons.mozilla.org/ru/firefox/addon/mind-for-firefox/>

## В чём проблема

Клиентский код i.Mind был написан во времена, когда для демонстрации экрана в
Chrome требовалось отдельное расширение (`chrome.desktopCapture`), а в Firefox
использовалось нестандартное API `navigator.getUserMedia({video: {mediaSource: ...}})`.
Современный Firefox давно поддерживает демонстрацию экрана через стандартный
`navigator.mediaDevices.getDisplayMedia()`, но:

- сайт по-прежнему проверяет браузер по `User-Agent` и просто **скрывает**
  кнопку демонстрации экрана для Firefox;
- старый код, который должен был обрабатывать Firefox, использует давно
  удалённые из браузера функции (`navigator.getUserMedia`,
  `navigator.legacyGetUserMedia`), поэтому даже без проверки браузера
  демонстрация не заработала бы.

## Что делает расширение

На страницах `e-class.tsu.ru` расширение:

1. Подменяет `navigator.userAgent` (только на этом сайте, только для этой
   вкладки) так, чтобы сайт думал, что это Chrome, — тогда кнопка
   демонстрации экрана появляется, а код идёт по «ветке Chrome» (с ожиданием
   ответа от расширения `chrome.desktopCapture`).
2. Эмулирует протокол этого несуществующего Chrome-расширения через
   `postMessage`, но вместо `chrome.desktopCapture` использует настоящий,
   нативный `navigator.mediaDevices.getDisplayMedia()` — то есть показывает
   обычный системный диалог выбора окна/экрана Firefox.
3. Подставляет отсутствующую в современном Firefox функцию
   `navigator.legacyGetUserMedia`, которую сайт в итоге вызывает, чтобы
   получить сам поток видео — и отдаёт туда поток, полученный на шаге 2.

Отдельно расширение чинит **поле ввода чата**. В Firefox оно иногда не
включается: полей нет, курсор не меняется, клик ничего не делает. Приложение
несколько раз подряд убирает и заново вставляет `iframe` редактора, после чего
Firefox не присылает ему событие `load`, которого ждёт редактор, и панель ввода
остаётся скрытой. Если через несколько секунд панель так и не появилась,
расширение само доставляет это событие (а при необходимости перезагружает
`iframe`).

Подмена `User-Agent` сделана без токена `AppleWebKit`, но с `Gecko` и
`Chrome/124`: приложение по-прежнему считает браузер Chrome, а GWT выбирает
для Firefox свою родную сборку (`gecko1_8`), а не Safari-сборку.

Никакие данные никуда не отправляются: всё происходит локально, в рамках
вкладки браузера.

## Избранные конференции

Кнопка расширения на панели инструментов открывает окно. Сверху в нём поле
«Имя для входа гостем», ниже список избранного, в самом низу форма добавления
конференции. Все значки в окне — простые одноцветные линейные SVG.

**Тема оформления.** Справа от заголовка окна есть кнопка-переключатель темы:
каждое нажатие переключает *тёмная → светлая → как в системе* (значок показывает
текущий режим: луна, солнце или монитор). Цвета берутся из палитры
`#06141B #11212D #253745 #4A5C6A #9BA8AB #CCD0CF`, роли которых в светлой теме
меняются местами; единственное исключение — фон светлой темы `#F2F2F5`.
По умолчанию включена тёмная тема. Выбор сохраняется и действует на все
страницы расширения (окно, напоминания, импорт и экспорт). Тема влияет только на
окна самого расширения, но не на сайт e-class.

Конференции хранятся **по номеру** — тому же, по которому вы входите на
`e-class.tsu.ru` через «вход по номеру». Адрес вкладки `#conference:…` для этого
не подходит: он привязан к вашей текущей сессии и в новой вкладке требует
авторизации.

- **Добавить** — введите номер конференции (пробелы допускаются) и, если
  хотите, название. Повторное добавление того же номера обновляет название,
  а не создаёт дубль.
- **Открыть** — клик по элементу списка открывает
  `https://e-class.tsu.ru/#login_by_id:<номер>` в новой вкладке. Это работает
  из любой вкладки. Приложение само разбирает номер из адреса и выполняет
  вход по номеру.
- Значки справа от названия: **часы** — расписание напоминаний (точка на
  значке означает, что расписание задано), **карандаш** — переименовать,
  **крестик** — удалить.
- **Импорт и экспорт** — значок со стрелками вверх и вниз справа от заголовка
  окна открывает страницу во вкладке (файловый диалог закрывал бы всплывающее окно).
  Экспорт сохраняет список (названия, номера и расписание напоминаний) в файл
  `mind-favorites-<дата>.json`; имя для входа гостем в файл не попадает.
  Импорт читает такой файл и **объединяет** его с текущим списком: новые номера
  добавляются, у существующих обновляются название и расписание (если оно есть
  в файле), ничего не удаляется. Некорректные записи пропускаются, а чужие
  файлы, слишком большие (больше 1 МБ) или с числом записей больше 1000
  отклоняются целиком. Файлы, сохранённые более ранними версиями (без
  расписания), тоже импортируются.
- **Имя для входа гостем** (необязательно) — если заполнено, то после входа по
  номеру страница ввода имени пропускается: расширение дописывает к адресу
  `#join:<токен>` часть `,true,<имя>`, и приложение входит гостем само. Это
  работает, только если для конференции разрешён гостевой вход без пароля;
  иначе вы увидите обычную страницу ввода имени. Запятые в имени заменяются
  пробелами.

Список и имя хранятся только локально в браузере (`storage.local`) и никуда не
отправляются. Расширению для этого нужно разрешение `storage`.

### Напоминания (необязательно)

Для каждой конференции можно задать расписание и получать уведомление перед
началом. **Это необязательная функция: расширение работает без неё, а
разрешение на показ уведомлений запрашивается только если вы сами включите
напоминания.**

- Значок часов у конференции открывает страницу настройки. Там конструктор:
  для каждого времени выбираются дни недели (Пн–Вс) и время начала; у одной
  конференции может быть несколько таких строк (например, пн 9:00 и ср 11:30).
  Расписание сохраняется само. Строка без дней или без времени не действует и не
  сохраняется. Подсказка у значка часов показывает текущее расписание.
- Чтобы уведомления приходили, нажмите на этой странице «Включить
  напоминания». Только тогда Firefox спросит **необязательное разрешение**
  `notifications` (показ уведомлений). Если отказаться или никогда не нажимать
  эту кнопку, расписание просто хранится, а уведомлений нет. Отключить
  напоминания можно там же («Отключить напоминания»): разрешение снимается,
  будильники удаляются, расписание остаётся.
- Разрешение `alarms` (таймеры) в Firefox нельзя сделать необязательным, поэтому
  оно объявлено сразу, но само по себе ничего не делает: без разрешения на
  уведомления расширение не создаёт ни одного таймера.
- «Напомнить за N мин.» (по умолчанию 5, от 0 до 60) настраивается там же.
- Клик по уведомлению открывает конференцию так же, как клик по элементу списка,
  в том числе с подстановкой имени для входа гостем.
- Время считается по местному времени компьютера. Если компьютер был выключен
  или спал и напоминание опоздало больше чем на 10 минут, уведомление не
  показывается — оно уже не имеет смысла; следующее напоминание по расписанию
  при этом не теряется. Для работы Firefox должен быть запущен.

### Сообщения чата в фоне (необязательно)

На странице напоминаний есть флажок «Сообщать о новых сообщениях, пока вкладка
в фоне» (по умолчанию выключен). Когда он включён и вкладка с конференцией не
на виду:

- в заголовке вкладки появляется счётчик «(N)», он сбрасывается, когда вы
  возвращаетесь на вкладку;
- если выдано разрешение на уведомления (то же, что для напоминаний), приходит
  всплывающее уведомление с текстом последнего сообщения; клик по нему
  открывает вкладку конференции.

Чтобы поток сообщений (например, 40 штук в конце пары) не превратился в поток
уведомлений, уведомление всегда одно и то же: при новых сообщениях в нём
обновляются число («новых сообщений: N») и текст последнего, не чаще раза в
секунду. Сообщения, которые уже были в чате при его открытии, не считаются.

Фоновый скрипт (`src/background/background.js`) нужен только для напоминаний и уведомлений о чате. Пока разрешение
на уведомления не выдано, он ничего не делает.

## Если платформа изменилась

Расширение рассчитано на конкретную версию клиента i.Mind. Если что-то из того,
на что оно опирается, перестаёт работать, на странице появляется небольшое окно
с пояснением вместо тихой поломки:

- браузер не умеет `getDisplayMedia` (нужен более новый Firefox);
- браузер отклонил запрос демонстрации экрана не из-за отмены выбора;
- экран выбран, но сайт за 15 секунд не запросил видеопоток (скорее всего,
  i.Mind обновился);
- поле ввода чата не запустилось даже после попыток расширения его починить.

Отмена выбора экрана ошибкой не считается. В окне есть кнопка «Скопировать
диагностику»: версия расширения, браузер, адрес сайта без части после `#` и коды
проблем. Токены и номера конференций туда не попадают. Приложите её к
[обращению на GitHub](https://github.com/zxcdurak/Mind-Share-Screen/issues).

## Ограничения

- Расширение заточено под конкретную (устаревшую) версию клиентского кода
  i.Mind, развёрнутую на `e-class.tsu.ru`. Если вуз обновит платформу
  i.Mind, логика может перестать работать и потребовать правки.
- Подмена `User-Agent` действует только на `e-class.tsu.ru`, на остальные
  сайты не влияет.

## Установка

### Вариант 1 — из каталога дополнений Firefox (рекомендуется)

Откройте <https://addons.mozilla.org/ru/firefox/addon/mind-for-firefox/> в
Firefox и нажмите «Добавить в Firefox». Расширение подписано Mozilla и
останется установленным после перезапуска браузера.

Чтобы расширение работало в приватных окнах, разрешите это в `about:addons` →
Mind for Firefox → «Запуск в приватных окнах».

### Вариант 2 — временная установка из исходников (для тестов)

1. Скачайте этот репозиторий (Code → Download ZIP) и распакуйте.
2. В Firefox откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите «Загрузить временное дополнение» (Load Temporary Add-on) и
   выберите файл `manifest.json` из распакованной папки.
4. Расширение заработает сразу, но слетит при перезапуске Firefox — придётся
   загружать заново.

## Как проверить, что всё работает

1. Зайдите на встречу в i.Mind на `e-class.tsu.ru`.
2. Нажмите кнопку демонстрации экрана — должна появиться кнопка (которой
   раньше не было) и системный диалог выбора окна/экрана.
3. Выберите окно или экран — трансляция должна начаться корректно.
4. Кликните в поле ввода чата — курсор должен стать текстовым, а сообщение
   набираться. Если панель ввода не появилась сразу, расширение включит её
   само примерно за 1–3 секунды.
5. Нажмите на кнопку расширения на панели инструментов — должно открыться окно
   «Избранные конференции».

## Структура проекта

```
manifest.json            манифест расширения
icons/                   значки расширения
src/
  page/                  скрипты, которые работают внутри страницы сайта
    inject.js            подмена браузера, демонстрация экрана
    chatfix.js           починка поля ввода чата
  content/               скрипты расширения на странице e-class.tsu.ru
    content.js           подключает скрипты из page/ в страницу
    guestname.js         вход гостем с готовым именем
    notice.js            окно «платформа изменилась»
    chatnotify.js        счётчик и уведомления о сообщениях чата
  background/
    background.js        напоминания и уведомления (фоновая страница)
  shared/                общий код и оформление страниц расширения
    common.js  theme.js  theme.css  icons.js
  popup/                 окно с избранным
  reminders/             страница напоминаний и настроек чата
  transfer/              страница импорта и экспорта
tests/                   автотесты на Node.js
```

## Тесты

Нужен только Node.js, зависимости не требуются. Каждый файл запускается отдельно:

```bash
node tests/bg-test.js
node tests/bg-chat-test.js
node tests/transfer-test.js
node tests/platform-test.js
```
