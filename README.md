# Mind for Firefox — фикс демонстрации экрана и чата i.Mind для Firefox

Расширение для Firefox, которое чинит демонстрацию экрана и поле ввода чата в
видеоконференциях **i.Mind** (используется, например, на `e-class.tsu.ru`) — там,
где сайт показывает ошибку вида «Используемый браузер не поддерживает технологию
трансляции рабочего стола» и предлагает установить Chrome, IE или Яндекс.Браузер.

**Установить из каталога дополнений Firefox:**
<https://addons.mozilla.org/ru/firefox/addon/mind-for-firefox/>

## В чём проблема

Клиентский код i.Mind был написан во времена, когда для демонстрации экрана в
Chrome требовалось отдельное расширение (`chrome.desktopCapture`), а в Firefox
использовалось нестандартное API `navigator.getUserMedia({video: {mediaSource: ...}})`.
Современный Firefox давно поддерживает демонстрацию экрана через стандартный
`navigator.mediaDevices.getDisplayMedia()`, но:

- сайт по-прежнему проверяет браузер по `User-Agent` и просто **скрывает**
  кнопку демонстрации экрана для Firefox;
- старый код, который должен был обрабатывать Firefox, использует давно
  удалённые из браузера функции (`navigator.getUserMedia`,
  `navigator.legacyGetUserMedia`), поэтому даже без проверки браузера
  демонстрация не заработала бы.

## Что делает расширение

На страницах `e-class.tsu.ru` расширение:

1. Подменяет `navigator.userAgent` (только на этом сайте, только для этой
   вкладки) так, чтобы сайт думал, что это Chrome, — тогда кнопка
   демонстрации экрана появляется, а код идёт по «ветке Chrome» (с ожиданием
   ответа от расширения `chrome.desktopCapture`).
2. Эмулирует протокол этого несуществующего Chrome-расширения через
   `postMessage`, но вместо `chrome.desktopCapture` использует настоящий,
   нативный `navigator.mediaDevices.getDisplayMedia()` — то есть показывает
   обычный системный диалог выбора окна/экрана Firefox.
3. Подставляет отсутствующую в современном Firefox функцию
   `navigator.legacyGetUserMedia`, которую сайт в итоге вызывает, чтобы
   получить сам поток видео — и отдаёт туда поток, полученный на шаге 2.

Отдельно расширение чинит **поле ввода чата**. В Firefox оно иногда не
включается: полей нет, курсор не меняется, клик ничего не делает. Приложение
несколько раз подряд убирает и заново вставляет `iframe` редактора, после чего
Firefox не присылает ему событие `load`, которого ждёт редактор, и панель ввода
остаётся скрытой. Если через несколько секунд панель так и не появилась,
расширение само доставляет это событие (а при необходимости перезагружает
`iframe`).

Подмена `User-Agent` сделана без токена `AppleWebKit`, но с `Gecko` и
`Chrome/124`: приложение по-прежнему считает браузер Chrome, а GWT выбирает
для Firefox свою родную сборку (`gecko1_8`), а не Safari-сборку.

Никакие данные никуда не отправляются: всё происходит локально, в рамках
вкладки браузера.

## Избранные конференции

Кнопка расширения на панели инструментов открывает окно со списком избранного:

- **Добавить** — откройте конференцию на `e-class.tsu.ru`, нажмите на кнопку
  расширения, при желании измените название и нажмите «Добавить текущую
  вкладку». Сохраняется полный адрес страницы (вместе с частью после `#`).
  Повторное добавление той же страницы обновляет название, а не создаёт дубль.
- **Открыть** — клик по элементу списка открывает конференцию в новой вкладке.
  Это работает из любой вкладки, не только с `e-class.tsu.ru`.
- **Переименовать** (✎) и **удалить** (✕) — кнопки справа от названия.

Список хранится только локально в браузере (`storage.local`) и никуда не
отправляется. Расширению для этого нужны разрешения `storage` и `activeTab`
(чтобы прочитать адрес и название текущей вкладки, когда вы нажали на кнопку).

Сохраняется адрес, а не «вход с именем»: если ссылка гостевая и содержит
одноразовый токен, после его истечения она перестанет работать. Автоматическое
заполнение имени на странице входа пока не реализовано.

## Ограничения

- Расширение заточено под конкретную (устаревшую) версию клиентского кода
  i.Mind, развёрнутую на `e-class.tsu.ru`. Если вуз обновит платформу
  i.Mind, логика может перестать работать и потребовать правки.
- Подмена `User-Agent` действует только на `e-class.tsu.ru`, на остальные
  сайты не влияет.

## Установка

### Вариант 1 — из каталога дополнений Firefox (рекомендуется)

Откройте <https://addons.mozilla.org/ru/firefox/addon/mind-for-firefox/> в
Firefox и нажмите «Добавить в Firefox». Расширение подписано Mozilla и
останется установленным после перезапуска браузера.

Чтобы расширение работало в приватных окнах, разрешите это в `about:addons` →
Mind for Firefox → «Запуск в приватных окнах».

### Вариант 2 — временная установка из исходников (для тестов)

1. Скачайте этот репозиторий (Code → Download ZIP) и распакуйте.
2. В Firefox откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите «Загрузить временное дополнение» (Load Temporary Add-on) и
   выберите файл `manifest.json` из распакованной папки.
4. Расширение заработает сразу, но слетит при перезапуске Firefox — придётся
   загружать заново.

## Как проверить, что всё работает

1. Зайдите на встречу в i.Mind на `e-class.tsu.ru`.
2. Нажмите кнопку демонстрации экрана — должна появиться кнопка (которой
   раньше не было) и системный диалог выбора окна/экрана.
3. Выберите окно или экран — трансляция должна начаться корректно.
4. Кликните в поле ввода чата — курсор должен стать текстовым, а сообщение
   набираться. Если панель ввода не появилась сразу, расширение включит её
   само примерно за 1–3 секунды.
5. Нажмите на кнопку расширения на панели инструментов — должно открыться окно
   «Избранные конференции».
