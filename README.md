# Mind Share Screen — фикс демонстрации экрана i.Mind для Firefox

Расширение для Firefox, которое чинит демонстрацию экрана в видеоконференциях
**i.Mind** (используется, например, на `e-class.tsu.ru`) — там, где сайт
показывает ошибку вида «Используемый браузер не поддерживает технологию
трансляции рабочего стола» и предлагает установить Chrome, IE или Яндекс.Браузер.

## В чём проблема

Клиентский код i.Mind был написан во времена, когда для демонстрации экрана в
Chrome требовалось отдельное расширение (`chrome.desktopCapture`), а в Firefox
использовалось нестандартное API `navigator.getUserMedia({video: {mediaSource: ...}})`.
Современный Firefox давно поддерживает демонстрацию экрана через стандартный
`navigator.mediaDevices.getDisplayMedia()`, но:

- сайт по-прежнему проверяет браузер по `User-Agent` и просто **скрывает**
  кнопку демонстрации экрана для Firefox;
- старый код, который должен был обрабатывать Firefox, использует давно
  удалённые из браузера функции (`navigator.getUserMedia`,
  `navigator.legacyGetUserMedia`), поэтому даже без проверки браузера
  демонстрация не заработала бы.

## Что делает расширение

На страницах `e-class.tsu.ru` расширение:

1. Подменяет `navigator.userAgent` (только на этом сайте, только для этой
   вкладки) так, чтобы сайт думал, что это Chrome, — тогда кнопка
   демонстрации экрана появляется, а код идёт по «ветке Chrome» (с ожиданием
   ответа от расширения `chrome.desktopCapture`).
2. Эмулирует протокол этого несуществующего Chrome-расширения через
   `postMessage`, но вместо `chrome.desktopCapture` использует настоящий,
   нативный `navigator.mediaDevices.getDisplayMedia()` — то есть показывает
   обычный системный диалог выбора окна/экрана Firefox.
3. Подставляет отсутствующую в современном Firefox функцию
   `navigator.legacyGetUserMedia`, которую сайт в итоге вызывает, чтобы
   получить сам поток видео — и отдаёт туда поток, полученный на шаге 2.

Никакие данные никуда не отправляются: всё происходит локально, в рамках
вкладки браузера.

## Ограничения

- Расширение заточено под конкретную (устаревшую) версию клиентского кода
  i.Mind, развёрнутую на `e-class.tsu.ru`. Если вуз обновит платформу
  i.Mind, логика может перестать работать и потребовать правки.
- Подмена `User-Agent` действует только на `e-class.tsu.ru`, на остальные
  сайты не влияет.

## Установка

### Вариант 1 — подписанная версия с addons.mozilla.org (рекомендуется)

Если у вас есть ссылка на подписанную версию на AMO — просто откройте её в
Firefox и нажмите «Добавить в Firefox». Расширение останется установленным
после перезапуска браузера.

### Вариант 2 — временная установка из исходников (для тестов)

1. Скачайте этот репозиторий (Code → Download ZIP) и распакуйте.
2. В Firefox откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите «Загрузить временное дополнение» (Load Temporary Add-on) и
   выберите файл `manifest.json` из распакованной папки.
4. Расширение заработает сразу, но слетит при перезапуске Firefox — придётся
   загружать заново.

## Как проверить, что всё работает

1. Зайдите на встречу в i.Mind на `e-class.tsu.ru`.
2. Нажмите кнопку демонстрации экрана — должна появиться кнопка (которой
   раньше не было) и системный диалог выбора окна/экрана.
3. Выберите окно или экран — трансляция должна начаться корректно.
