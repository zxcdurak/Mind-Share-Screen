# Mind for Firefox

Расширение для Firefox, с которым i.Mind на e-class.tsu.ru работает так же, как в Chrome. Без него в Firefox нет кнопки демонстрации экрана (сайт предлагает поставить Chrome, IE или Яндекс.Браузер), а поле ввода в чате иногда вообще не оживает.

Заодно в расширении есть список избранных конференций, необязательные напоминания о паре и уведомления о новых сообщениях в чате.

Установить: <https://addons.mozilla.org/ru/firefox/addon/mind-for-firefox/>

## Что умеет

**Демонстрация экрана.** На странице конференции появляется кнопка, по нажатию открывается обычный диалог Firefox с выбором окна или экрана.

**Чат.** Поле ввода запускается само, даже если без расширения оно остаётся мёртвым.

**Избранные конференции.** Кнопка расширения на панели открывает окно со списком. Конференции хранятся по номеру, тому же, который вы вводите при входе по номеру, и открываются в один клик из любой вкладки. Если указать имя для входа гостем, страница ввода имени пропускается (работает, когда у конференции разрешён гостевой вход без пароля).

**Импорт и экспорт.** Список вместе с расписанием сохраняется в json-файл и загружается обратно, например на другом компьютере. При импорте записи добавляются к текущему списку, у совпавших номеров обновляются название и расписание, ничего не удаляется. Имя для гостевого входа, тема и время «напомнить за N минут» в файл не попадают.

**Уведомления** (по кнопке с колокольчиком, всё необязательно):
- напоминание перед парой по расписанию: для каждой конференции можно задать несколько строк вида «пн, ср — 9:00»;
- сообщения чата, пока вкладка в фоне: в заголовке вкладки появляется счётчик, а при выданном разрешении ещё и всплывающее уведомление. Оно всегда одно: при потоке сообщений в нём обновляются число и текст последнего, не чаще раза в секунду, так что 40 сообщений после пары не превратятся в 40 уведомлений.

Разрешение на показ уведомлений Firefox спрашивает только после нажатия «Включить уведомления» на этой странице. Не включите, и расширение просто работает без них.

**Тема.** Тёмная, светлая или как в системе, переключается кнопкой в окне расширения. Меняется только оформление самого расширения, сайт не затрагивается.

**Диагностика.** Кнопка с пульсом открывает страницу, где видно состояние расширения, последнее событие по каждой функции и журнал. Если что-то сломалось, нажмите там «Скопировать всё» и приложите текст к [обращению на GitHub](https://github.com/zxcdurak/Mind-Share-Screen/issues). В журнал пишутся только технические пометки, без текстов сообщений, имён и номеров конференций.

Если i.Mind обновится и расширение перестанет его понимать (например, экран выбран, а сайт так и не запросил видеопоток), на странице появится небольшое окно с объяснением, а не тихая поломка.

## Приватность

Всё происходит в вашем браузере. Расширение ничего никуда не отправляет, список, расписание и журнал лежат в локальном хранилище Firefox. Нужны разрешения `storage` и `alarms`, плюс необязательное `notifications`. Таймеры `alarms` Firefox нельзя сделать необязательными, но без разрешения на уведомления расширение не создаёт ни одного.

## Установка

Проще всего из каталога дополнений по ссылке выше. Чтобы расширение работало в приватных окнах, включите это в `about:addons` → Mind for Firefox → «Запуск в приватных окнах».

Из исходников, для проверки: скачайте репозиторий, откройте `about:debugging#/runtime/this-firefox`, нажмите «Загрузить временное дополнение» и выберите `manifest.json`. Такое расширение пропадёт после перезапуска Firefox.

## Как это устроено

Клиент i.Mind писали, когда Chrome для демонстрации экрана требовал отдельного расширения, а Firefox обходился своим нестандартным API. Сейчас Firefox умеет `getDisplayMedia()`, но сайт этого не знает: он смотрит на `User-Agent`, прячет кнопку и обращается к функциям, которых в браузере давно нет. Расширение подстраивается под это в трёх местах.

1. Подменяет `User-Agent` на странице так, чтобы сайт принял Firefox за Chrome и показал кнопку. Подмена работает только на e-class.tsu.ru. Строка сделана без `AppleWebKit`, иначе GWT выберет для Firefox сборку под Safari.
2. Изображает несуществующее Chrome-расширение: отвечает на его сообщения `getScreen` и `gotScreen`, а экран берёт через `getDisplayMedia()`.
3. Подставляет `navigator.legacyGetUserMedia`, через которую сайт в конце забирает поток, и отдаёт ему тот, что выбран в диалоге.

Чат ломается по другой причине. Приложение несколько раз подряд вынимает `iframe` редактора и вставляет заново, после чего Firefox не присылает ему событие `load`, которого ждёт редактор. Если панель ввода не появилась за пару секунд, расширение само отправляет это событие, а если не помогло, перезагружает `iframe`.

Скрипты на странице подключаются обычными тегами `<script>`, чтобы они работали в том же контексте, что и сайт. Через `wrappedJSObject` это давало случайные ошибки «Permission denied to access object».

Расширение подогнано под конкретную версию клиента i.Mind (3.17) на e-class.tsu.ru. После обновления платформы что-то может понадобиться поправить.

### Структура

```
manifest.json
icons/
src/
  page/           скрипты внутри страницы сайта
    inject.js       подмена браузера, демонстрация экрана
    chatfix.js      починка поля ввода чата
  content/        скрипты расширения на e-class.tsu.ru
    content.js      подключает page/ к странице
    guestname.js    вход гостем с готовым именем
    notice.js       окно «что-то пошло не так», события в журнал
    chatnotify.js   счётчик и уведомления о чате
  background/     напоминания и уведомления
  shared/         общий код и оформление
  popup/          окно со списком избранного
  notifications/  страница уведомлений
  transfer/       импорт и экспорт
  diagnostics/    страница диагностики
tests/            автотесты на Node.js
```

### Тесты

Нужен только Node.js, ничего устанавливать не надо:

```bash
node tests/bg-test.js
node tests/bg-chat-test.js
node tests/transfer-test.js
node tests/platform-test.js
```
